版ごとの帰属

作曲者・版・該当箇所・組版や原資料の帰属は、各カードの「出典・検証範囲・利用条件」に記載しています。掲載版は Mutopia Project のライセンス表示で Public Domain と表示されたものです。表記はこの版を指し、他版、他者による録音、歌詞やすべての法域に適用されるという意味ではありません。

音声の範囲

試聴は、掲載版の楽譜とMIDIを照合した短い抜粋の独自合成です。元の演奏録音・歌声ではありません。原楽譜・原MIDIは掲載していません。楽曲全体の形式・演奏法を検証したものではありません。
