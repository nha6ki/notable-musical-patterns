2拍の小節周期（2/4拍子）

四分音符を1拍として、2拍をひとまとまりにする小節の枠組みです。各拍の中にいくつ音があるかとは別で、細かい発音が続いても小節の周期は2拍のままです。

聞きどころ：サンバ・エンレードの合奏で、細かな打音に引っ張られず「1・2」を繰り返してみます。録音の拍注釈を手がかりに二つ数えるごとの区切りを追います。抜粋の最初の音は「1」とは限りません。
