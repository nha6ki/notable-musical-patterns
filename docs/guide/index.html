カノン

同じ旋律が時間差で重なる

先に始めた声部の旋律を、別の声部が一定の規則で追います。音の高さをずらすだけでなく、長さや動く方向を変えることもあります。

上声 第1〜2小節 → 下声 第5〜6小節

聞きどころ：約6秒で、冒頭の旋律が1オクターヴ低い声部から聞こえます。

ペダル音

低音がとどまり、上の和声が動く

同じ音を長く保つ、または打ち直して保つ間に、ほかの音が変化します。ここでいう「ペダル」は、ピアノのペダルを踏む操作ではありません。

バッハ《平均律クラヴィーア曲集》第1巻 ハ長調前奏曲 BWV 846

第32〜35小節

聞きどころ：いちばん低いドは0、2、4、8、12秒で打ち直されます。最初はド・ミ・ソ・シ♭、最後はド・ミ・ソ。低音がドになった瞬間と、曲がハ長調の主和音で閉じる瞬間を聞き分けます。

和声

偽終止

「終わりそう」で、別の和音へ進む

主和音に向かうと予想されるところで、別の和音に進みます。同じ和音の並びが現れても、そこでフレーズが区切れるとは限りません。

  • 属七 V7
  • 主和音ではなく
  • 第6音上の和音 VI

ショパン《前奏曲 ホ短調》Op.28-4

第20〜21小節・両手（聞きどころは第20小節末から）

聞きどころ：約3.21秒でシを低音とする属七へ。約4.29秒で、主音のミではなくドへ進みます。第21小節頭のド・ミ・ソと、その後に現れるシ♭は分けて聴きます。試聴は同版MIDIの合成で、ペダルや演奏表情は再現していません。

アルベルティ・バス

低→高→中→高で和音を刻む

和音を同時に鳴らさず、低い音・高い音・中間の音・高い音の順で繰り返す伴奏です。「低」は音の高さであり、必ず和音の根音という意味ではありません。

雅楽

笙の合竹（あいたけ）

複数の管の音で旋律を彩る

雅楽の笙は、いくつかの管を同時に鳴らして合竹という音のまとまりを作ります。合竹が替わっても残る音と、入れ替わる音に注目します。

平調《越殿楽》

1894年『鳳笙譜』国立国会図書館 コマ37・右頁右端

聞きどころ：0.50秒で凡→一、1.00秒で一→乙。凡→一では6音中5音が共通です。構成音を等長で並べた電子音で、雅楽の拍節、手移り、息づかい、音色の再現ではありません。
