# Notable Musical Patterns

短い試聴、解説、確認できる出典から、音楽のパターンを探すサイトです。パターン図鑑、概念からの検索、資料別カタログをつなぎ、音楽的なアイデアから実例へ進み、その根拠と確認範囲をたどれるようにしています。

**[日本語サイトを開く](https://nha6ki.github.io/notable-musical-patterns/)** · [English website](https://nha6ki.github.io/notable-musical-patterns/en/) · [English README](README.md)

## 使い始める

- **[パターン図鑑](https://nha6ki.github.io/notable-musical-patterns/guide/)**：105ラベルの解説と聴きどころを読む。
- **[概念を探す](https://nha6ki.github.io/notable-musical-patterns/explore/)**：概念から試聴例を検索する。同じ例に複数のラベルを付けられます。根拠付きの代表例を上位に表示し、それ以外の一致例も残します。
- **[データセット](https://nha6ki.github.io/notable-musical-patterns/datasets/)**：資料別に探し、帰属と利用条件を確認する。サイト内試聴、外部試聴リンク、出典参照のみの項目を区別しています。

### 現在の掲載範囲

| 指標 | 件数 | 数えているもの |
| --- | ---: | --- |
| データセット・資料群 | 16 | 掲載する資料群 |
| カタログ項目 | 6,729 | 検索できるレコード。独立した作品数ではありません |
| サイト内音源のある項目 | 2,983 | 横断カタログ内の試聴項目 |
| サイト内音源のない項目 | 3,746 | 外部試聴リンクを含む出典参照項目 |
| 外部試聴リンク | 578 | 上記3,746項目の内数 |
| 図鑑カード | 105 | 解説するラベル。独立検証済み概念105件という意味ではありません |

これらは本サイトの掲載範囲であり、各原資料の総数ではありません。例えばMutopiaの試聴1,168件は1,094版に対応し、WeimarとJSMelは個別データではなく概要レコードを掲載しています。図鑑には、横断カタログの音源件数とは別に確認したショパンのデモもあります。

## 根拠と再利用

データセットが付けたラベル、抜粋内の局所的な観察、名称付きパターンの検証は、それぞれ異なる根拠です。楽譜から生成したMIDIは独立した演奏資料ではありません。外部試聴リンクは別演奏の場合があり、地域やアカウントによって利用できないことがあります。

再利用の前に、[掲載範囲と資料別の利用条件](https://nha6ki.github.io/notable-musical-patterns/datasets/release-notes.html)と各項目の帰属表示を確認してください。リポジトリのライセンスは、録音、楽譜、原作品、第三者データセットへの包括的な利用許可ではありません。

- 音声・第三者素材：出典と各項目の利用条件に従います。リンクの掲載は、参照先素材の再利用を許可するものではありません。

## ローカルで動かす

現行サイトは `docs/` 内の静的HTML・CSS・JavaScriptで構成され、アプリケーションサーバーやビルド処理は不要です。Python 3.9以降でローカル配信と検査を行えます。pipやnpmでの追加インストールは不要です。リポジトリには音声ファイルも含むため、全体を取得する場合はディスク容量を確保してください。

リポジトリのルートで実行します。

```sh
git clone https://github.com/nha6ki/notable-musical-patterns.git
cd notable-musical-patterns
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

日本語版は <http://127.0.0.1:8000/>、英語版は <http://127.0.0.1:8000/en/> を開きます。HTMLファイルを直接開かず、HTTPサーバー経由で確認してください。サーバーはCtrl+Cで終了できます。外部の出典・試聴リンクにはインターネット接続が必要です。 「概念で探す」の再生はローカル表示時も公開サイトの音源を参照します。図鑑と資料一覧では、チェックアウトした音源を使います。

別のターミナルで、同じリポジトリのルートから検査します。

```sh
python3 tools/check_release.py --root .
python3 -m unittest discover -s tests -v
```

公開前検査スクリプトはローカルファイルを読み、通信やファイル変更を行いません。2つ目のコマンドはユニットテストを実行します。構造的な公開要件の検査であり、実聴、権利の確定、ブラウザ動作確認の代わりにはなりません。別途必要なブラウザ確認と公開確認は [RELEASE-CHECKS.md](RELEASE-CHECKS.md) を参照してください。ローカルでの編集や配信だけでは公開されません。

変更は目的を絞り、出典と権利情報を維持してください。内容の修正と公開の承認は別に扱います。データ変更や音声追加の前に貢献ガイドを確認してください。

## v0.1.0のオフライン保存版

[v0.1.0リリース](https://github.com/nha6ki/notable-musical-patterns/releases/tag/v0.1.0)は、**8例のオフライン検索ガイド**です。現行の6,729項目サイトのスナップショットではありません。検証は指定した版・箇所を対象とし、作品全体を検証したものではありません。この保存版はメタデータと検索コードのみで、楽譜、MIDI、録音、出典の図、既存データセットの抜粋を含みません。一方、現行サイトには試聴音声があります。

保存版8例の検索にはPython 3だけを使い、ファイルの送受信は行いません。

```sh
python3 search.py
python3 search.py バッハ --json
python3 search.py --concept deceptive_cadence
```

複数の検索語はAND検索です。概念フィルターは概念IDまたは日本語ラベルの完全一致を使います。JSON出力には版、位置、根拠、出典、帰属を含みます。

`MANIFEST.sha256` は**元のv0.1.0アーカイブ専用**で、`docs/`、現行サイト、その音声を対象にしません。文書更新後の作業ツリーではなく、元のリリースを展開したファイルに対して検証してください。文書の更新により、過去のハッシュと異なる場合があります。
