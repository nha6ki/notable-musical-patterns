# Notable Musical Patterns

## 現行サイトと保存版の区別

現行の[GitHub Pagesサイト](https://nha6ki.github.io/notable-musical-patterns/)は `docs/` から公開しています。**16データセット・資料群、6,729検索項目、横断カタログ内の試聴2,983件、105ラベルの解説カード**を収録しています。これらは独立した作品数や、すべて独立検証済みの概念数ではありません。[掲載範囲と資料別の利用条件](docs/datasets/release-notes.html)、[パターン図鑑](docs/guide/index.html)、各項目の帰属表示を参照してください。現行サイトには試聴音声がありますが、以下の保存版にはありません。

ルートの `catalogue.json`、`search.py` と8例の出典一覧は、**v0.1.0のオフライン保存版**です。現行サイトの全項目ではありません。以下の「音声等を同梱しない」という説明は、この8例の保存版に限ります。

`MANIFEST.sha256` は **v0.1.0保存版専用**で、`docs/`、現行サイトや音声ファイルを検証するものではありません。チェックサムは当時のファイルに対応するため、文書更新後の作業ツリーではなく、元のv0.1.0アーカイブに対して検証してください。

## v0.1.0オフライン保存版

実作品の音楽パターンを、作品・版・箇所から探せる検索ガイドです。バージョン0.1.0の**8例**は、対象箇所を楽譜と同じ版のMIDIで確認しています。曲全体を検証したわけではなく、楽譜から生成したMIDIは独立した演奏資料ではありません。

### 保存版8例の検索

フォルダを展開し、Python 3で次のように実行します。追加ライブラリやネット接続は不要です。

```sh
python3 search.py
python3 search.py バッハ --json
python3 search.py ハバネラ
python3 search.py --concept deceptive_cadence
```

検索語が複数ならAND検索、`--concept` は概念IDまたは日本語概念名の完全一致です。作品・版・箇所・確認範囲・出典と帰属を表示します。

`SOURCES.md` は出典一覧、`LICENSE` と `LICENSE-DATA.md` は、検索コードと独自メタデータ・文書の利用条件です。`MANIFEST.sha256` は、対応環境で `sha256sum -c MANIFEST.sha256` を実行すると検査できます。

楽譜、MIDI、録音、出典の図、既存データセットの抜粋は同梱していません。リンクを掲載しても、参照先素材の利用を許可することにはなりません。
